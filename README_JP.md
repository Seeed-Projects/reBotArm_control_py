現行の RS URDF は実測した質量と重心を使用しています。モデル全体の質量は 6.5503 kg で、グリッパーの各指は 55.9 g、ストロークはそれぞれ 0～50 mm です。 [URDF ファイル](urdf/RS/urdf/ReBot_Arm_RS.urdf)
