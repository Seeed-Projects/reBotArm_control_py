## Modèle RS actuel

L’URDF RS actuel utilise les masses et centres de masse mesurés. La masse totale du modèle est de 6,5503 kg. Chaque doigt du préhenseur pèse 55,9 g et sa course est de 0 à 50 mm. [Fichier URDF](urdf/RS/urdf/ReBot_Arm_RS.urdf)
